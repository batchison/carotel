    Section Introduction to Functions: Practice Exam

    This is a sample assessment for an introduction to functions course.
    🔗

    Exercises Exercises

    1.

    Create a table with at least two points and graph the following function. Then state the domain, range, and the equation of the horizontal asymptote.
    \begin{equation*} f(x) = 2^{x-1} + 3 \end{equation*}
    🔗
    NOTE: You MUST make your graph on a separate paper.
    🔗
    🔗

    2.

    Create a table with at least two points and graph the following function. Then state the domain, range, and the equation of the vertical asymptote.
    \begin{equation*} g(x) = \log_2(x) \end{equation*}
    🔗
    NOTE: You MUST make your graph on a separate paper.
    🔗
    🔗

    3.

    Create a table with at least two points and graph the following function. Then state the domain, range, and the equation of the vertical asymptote.
    \begin{equation*} h(x) = \log_3(x-4) + 2 \end{equation*}
    🔗
    NOTE: You MUST make your graph on a separate paper.
    🔗
    🔗

    4.

    Rewrite each expression using exponential form.
    🔗

    (a)

    \(\log_2 16 = x\)
    🔗

    (b)

    \(\log_5\left(\frac{1}{125}\right) = x\)
    🔗
    🔗
    🔗

    5.

    Evaluate without a calculator:
    🔗

    (a)

    \(\log_4 64\)
    🔗

    (b)

    \(\log_{10} 0.01\)
    🔗
    🔗
    🔗

    6.

    Simplify using the properties of exponents.
    🔗

    (a)

    \(x^3 \cdot x^5\)
    🔗

    (b)

    \(\frac{a^9}{a^4}\)
    🔗

    (c)

    \((2x^3)^4\)
    🔗

    (d)

    \((x^2y^3)^2\)
    🔗

    (e)

    \(\frac{5^6}{5^{-2}}\)
    🔗
    🔗
    🔗

    7.

    Rewrite each equation using the other form.
    🔗

    (a)

    \(3^4 = 81\)
    🔗

    (b)

    \(\log_2 16 = 4\)
    🔗

    (c)

    \(\log_5 125 = 3\)
    🔗

    (d)

    \(10^2 = 100\)
    🔗
    🔗
    🔗

    8.

    Evaluate each logarithm.
    🔗

    (a)

    \(\log_{10} 1000\)
    🔗

    (b)

    \(\log_2 32\)
    🔗

    (c)

    \(\log_3 81\)
    🔗

    (d)

    \(\log_4 16\)
    🔗

    (e)

    \(\log_5\left(\frac{1}{25}\right)\)
    🔗
    🔗
    🔗

    9.

    Solve each exponential equation.
    🔗

    (a)

    \(2^x = 16\)
    🔗

    (b)

    \(5^{x-1} = 25\)
    🔗
    🔗
    🔗

    10.

    Solve each logarithmic equation.
    🔗

    (a)

    \(\log_2(x) = 5\)
    🔗

    (b)

    \(\log(x-3) = 2\)
    🔗
    🔗
    🔗

    11.

    Solve each logarithmic equation after using log properties to write as a single logarithm.
    🔗

    (a)

    \(\log_2(x) + \log_2(5) = 3\)
    🔗

    (b)

    \(\log(x-3) - \log(4) = 1\)
    🔗
    🔗
    🔗
    🔗
